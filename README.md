# VMS — Visite Managériale de Sécurité · CDES

Page publique de l'outil VMS (GitHub Pages). Version V2 du 05/10/2026.

| Fichier | Rôle |
|---|---|
| `index.html` | la page (structure seulement) |
| `css/vms.css` | la mise en forme |
| `js/vms.js` | le fonctionnement (observations, IA, PDF, envoi) |
| `data/listes.json` | activités et mémo FHO — modifiables ici sans toucher au code |
| `regles.png`, `fho.png`, `CDES_Logo.png` | images de l'aide |

**Ce dépôt ne contient ni adresse de serveur, ni mot de passe, ni nom de personne.**
L'appareil est « branché » au serveur CDES en ouvrant la VMS depuis la tuile de
l'intranet HSE. La liste des responsables arrive du serveur (Référentiel CDES),
seulement sur un appareil branché. Sans branchement, on peut remplir la visite et
enregistrer le PDF ; l'envoi au plan d'actions et par mail attend le branchement.
